# X Layer Guardian: Reference-Informed Dark Product System

## What to Carry Forward

The supplied reference succeeds because it is **one coherent product**, not a collection of cards. It uses a near-black foundation, a small number of large purposeful blocks, strong spacing, rounded tactile surfaces, bright green only for primary progress or action, and a predictable bottom navigation. Information is dense but never noisy because every block has a single job.

Guardian will adopt these traits without copying the meal-tracking subject matter or exact layout. Its primary content becomes transaction confidence: the user’s current review state, the significant security consequence, and a compact confidence summary. Bright green means trusted or actionable; warm red means a permission danger; muted blue is reserved for neutral chain evidence.

## Guardian Mobile Information Architecture

| Area | Guardian-specific role |
| --- | --- |
| Top greeting/status | Identifies the current review mode and current security state. |
| Confidence block | Shows the selected transaction’s decision signal and one recommendation. |
| Review cards | Shows consequence, state simulation, and chain evidence in a compact, tactile sequence. |
| Case navigator | Gives immediate access to all six demo cases through a grid or modal, never horizontal scrolling. |
| Bottom navigation | Provides stable destinations: Review, Cases, Inspect, Activity, and Account. |

## Desktop Adaptation

Desktop uses the same visual language—near-black background, lime trust signal, rounded blocks, refined shadows, and the same navigation vocabulary—rather than converting into a light dashboard. The desktop version may add a secondary evidence column, but the mobile reading order remains intact.

## Guardrails

The reference informs the mood, hierarchy, density, and tactile quality only. Guardian retains its own security semantics, X Layer data, existing wallet boundary, deterministic rules, and responsive requirements. No user-provided visual asset will be copied into the deployed product.
