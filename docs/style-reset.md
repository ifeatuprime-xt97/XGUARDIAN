# X Layer Guardian: Style Reset

## Retained Palette

The existing palette remains: warm mineral paper as the base, dense forest ink for authority, restrained guardian green for a verified or active state, and the existing amber and red only for review and stop conditions. This palette is distinctive and should remain recognisable.

## Replaced Style System

The serif, archival-dossier direction is being removed. The updated product will use **IBM Plex Sans** for every decision, label, and headline, paired with **IBM Plex Mono** only for chain identifiers and technical values. This is a sharper, more functional type system that better fits a transaction-security product.

The interface will shift from a document metaphor to a **review terminal**: dark ink navigation, rounded control surfaces, focused confidence blocks, and clean segmented evidence. Content still follows the same inspection sequence—verdict, consequence, expected effect, evidence—but the interaction feels like a tool rather than a stylised report.

## Rules

Typography will establish hierarchy through weight, scale, and rhythm rather than a display serif. Green is reserved for trusted, active, or cleared events. Technical information remains quiet but selectable, and the mobile interface retains the same hierarchy without decorative staging.
