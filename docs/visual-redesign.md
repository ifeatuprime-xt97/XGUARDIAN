# X Layer Guardian: Visual Redesign Direction

## Intent

The previous interface treated every detail as equally important and therefore read as a generic crypto dashboard. The replacement experience will behave like a **transaction decision dossier**: one decisive answer first, one consequence second, and evidence only when the user needs it.

## Visual Language

The product will move from dark neon-console styling to a high-contrast editorial system. Warm paper, dense ink, a sharp signal green, and disciplined danger red create a more credible security identity. The visual metaphor is a signed-off inspection document rather than a trading terminal. Large serif decision language is paired with compact monospace evidence, while hard rules, thin dividers, and numbered scenario markers make the review feel deliberate and procedural.

## Review Flow

| Order | What the user sees | Purpose |
| --- | --- | --- |
| 1 | A permanent mode tag and selected scenario | Distinguishes demo evidence from wallet-connected inspection. |
| 2 | A large verdict | Answers whether to pause, inspect, or proceed before any dense data appears. |
| 3 | The single primary consequence | States the exact permission, transfer, or call in plain language. |
| 4 | The expected asset effect | Shows what leaves the account, what is approved, and what remains unknown. |
| 5 | Supporting evidence | Reveals simulation, reputation, raw calldata, and receipt status in a low-emphasis ledger. |

## Guardrails

The redesign will not use decorative charts, token-price widgets, generic AI chat, glowing cards, or excess dashboard chrome. Severity colors will have single roles: green for a cleared deterministic finding, red for a critical stop, amber for a review-required condition, and blue-grey for neutral evidence. The layout must remain responsive, accessible, and legible with only a few viewable units at a time.
