# Guardian Mobile and Typography Reset

## Type Direction

Guardian will replace its broad default sans treatment with **Manrope** for all human-facing content. Manrope gives the security portfolio a warmer, more deliberate product voice at compact sizes while retaining clear numeric and wallet-address reading. **IBM Plex Mono** remains restricted to small technical metadata, selectors, and chain-specific labels.

| Role | Typeface | Weight | Mobile size |
| --- | --- | --- | --- |
| Product and page headline | Manrope | 500 | 28–32 px |
| Section title / security decision | Manrope | 500–600 | 18–24 px |
| Body and guidance | Manrope | 400–500 | 13–14 px |
| Technical label / address context | IBM Plex Mono | 400–500 | 10–11 px |

## Mobile Composition

The mobile Overview becomes a compact daily security surface rather than a compressed desktop page. The title area becomes transparent and economical; the active-wallet card receives the visual focus; case selection is a visible three-column command grid; and the selected next step remains a single unambiguous action. The desktop layout preserves the portfolio hierarchy but adopts the same new type system, spacing rhythm, and type contrast.
