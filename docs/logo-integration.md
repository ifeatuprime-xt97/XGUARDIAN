# X Layer Guardian: Sentinel Mark Integration

## Mark

The Guardian sentinel is a compact, original geometric mark with interlocking protective paths and an angular internal aperture. It uses the product’s acid-lime and deep-forest palette, with no text inside the asset so it remains readable at small sizes.

## Integration Points

| Surface | Usage |
| --- | --- |
| Header | Primary identity mark beside the Guardian wordmark. |
| Active-wallet card | Compact portfolio identity cue beside the selected wallet context. |
| Profile | Enlarged boundary and trust marker. |
| Browser metadata | PNG favicon for browser tabs and installed-app surfaces. |

## Validation Outcome

The mark was reviewed in the running interface at 375 px mobile width and 1280 px desktop width. It remains distinct from nearby text and controls, fits without clipping in the 27 px header container, and supports the active-wallet card without making the primary wallet label less prominent. The logo is an image asset only; Guardian’s client-side signing and portfolio behavior are unchanged.
