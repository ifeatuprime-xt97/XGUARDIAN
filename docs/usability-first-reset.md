# X Layer Guardian: Usability-First Reset

## Principle

X Layer Guardian should reward repeated use with **calm precision**. A user returns because the workspace feels reliable, legible, and quietly premium—not because it performs urgency. The interface must make routine transaction review easier over time, with visual character created through proportion, material, typography, and detail rather than spectacle.

## Navigation Contract

Every inspection case must be reachable without horizontal scrolling, hidden overflow, or gesture discovery.

| Viewport | Case navigation | Requirement |
| --- | --- | --- |
| Desktop and laptop | A compact, persistent vertical case list beside the review workspace. | All six cases are visible and selectable in one glance. |
| Tablet | A stable 3×2 case grid above the review workspace. | No side-scroll or collapsed navigation state. |
| Mobile | A stable 2×3 case grid directly below the page heading. | Each option has a visible label and tap target; no carousel behavior. |

## Product Surface

The primary surface becomes a **review workspace**, not an intercept theater. Its first view presents the selected transaction title, a clear risk signal, a short human summary, and the one action to take. Supporting evidence is grouped below in quiet, purpose-specific areas: transaction effect, deterministic findings, and chain evidence.

The palette stays distinctive—warm mineral paper, forest ink, pale guardian green, amber, and red—but color serves only state and hierarchy. The visual system uses a calm Manrope interface font with IBM Plex Mono reserved for values and provenance. Spacious alignment, quiet separators, clear tabular rhythm, and a restrained depth system create enduring visual appeal.

## Interaction Policy

Navigation, tabs, and primary actions receive subtle hover/focus feedback only. Case changes should be immediate and retain scroll position; no large entrance sequences should disorient habitual users. All optional motion must defer to `prefers-reduced-motion`.
